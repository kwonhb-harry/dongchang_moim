# 🎓 동창 모임 초대장 & 참석 투표 (RSVP)

불필요한 회비 항목을 제외하고, **토스(Toss) 스타일의 심플한 디자인**과 **다음 모임에도 계속 재사용할 수 있는 공지 변경 기능**을 갖춘 모바일 모임 웹앱입니다.

---

## 📌 핵심 기능

1. **📢 모임 공지 & 간편 재사용 (회비 제외)**
   - **1인 회비 항목을 제외**하여 모임 일시, 장소(카카오맵 위치보기), 안내글만 단정하게 표시
   - 상단 **[✏️ 공지 변경]** 버튼을 통해 모임명, 날짜, 시간, 장소, 안내글을 언제든 수정 가능
   - **[🗑️ 새 모임 시작 (이전 참석자 명단 비우기)]** 버튼 제공: 다음 모임, 봄/가을 정기모임, 송년회 때 이전 투표 명단만 1초 만에 비우고 새 모임을 바로 시작할 수 있습니다.

2. **🗳️ 초간단 참석 결정 & 불참 사유 입력**
   - 이름 입력
   - **[ 🟢 참석합니다 ]** vs **[ 🔴 불참합니다 ]** 원터치 선택
   - **불참 선택 시**: 불참 사유 입력창이 자동으로 나타나 간단한 이유(출장, 가족 행사 등) 작성

3. **📊 최종 참석 인원 집계 & 엑셀(CSV) 다운로드**
   - 참석 **O명** | 불참 **O명** 실시간 카운트
   - 참석자 명단 태그
   - 불참자 명단 및 불참 사유 리스트
   - **엑셀(CSV) 다운로드**: 한글 깨짐 없는(UTF-8 BOM) 참석자/불참사유 명단 파일 즉시 다운로드
